# 退役五门上线验收，台账降为质量仪表盘

日报的「五门线上验收」自 2026-07-22 起运行，从未攒满过任何一门。原因不是运气，是机制与开发节奏结构性冲突：共享运行时指纹覆盖 `daily_news.py`、`rollout_validation.py`、`article_extractor.py`、`requirements.txt` 四个日常会改的文件，而 `issue_ledger.py` 的 `RUNTIME_RESET_GATES = GATES` 让指纹一变就重置**全部五门**。文档曾声称累计型的 enrich 与 source_metrics「只统计有效日、缺数据不清零」，但那条豁免只对「某天没有数据」成立，对指纹变化不成立——两类门在指纹变化面前一样归零。

决定退役「攒够 N 天 → 解锁 `objectivity active` / 解锁补源」这层语义。台账每日逐门记录保留，因为它本身是有用的质量仪表盘；被删除的只是「计数在通往某个开关」这个含义。`objectivity.mode` 的 `interim` 从过渡态变为终局。

本决策取代 ADR 0015 结尾关于「重新通过四道门后才切 `active`」的前置条件。ADR 0015 的固定成本合同、证据分级和删除统计升级不受影响，仍然有效。

## 阻止条件

台账 2026-08-10 行的实数是 `selection 1/7`、`trajectory 1/5`、`enrich 0/5`、`objectivity_shadow 1/7`、`source_metrics 1/14`；同日提交的周综述自动审修改动了 `daily_news.py`，会让下一次 publish 把这些再次清零。最长的信源门要 14 个连续有效日，而管线平均每 1-3 天就有一次改动，因此该门在当前开发节奏下不可达。

`enrich` 的 5 日文字质量门另有独立阻塞：它需要人工回填文字质量判断，而这一步从未执行过，所以它与指纹无关地长期停在 0。

被考虑并否决的替代方案是冻结管线 14 天。否决理由是它把开发节奏让给了验收流程，而验收本身只是为了授权一个已决定不启用的模式。

## 决定

- 台账保留每日记录、指纹重置、失败清零和缺口冻结等全部机制，但不再计算解锁判定，也不再输出「待人工最终确认」。逐门进度不显示分母，避免读成「还差几天」。
- `objectivity.mode` 永久保持 `interim`。完整取证、独立证据链和定向修复的代码继续只在 shadow 下运行。
- 客观性 shadow 按累计样本封顶：既有样本视为已足够，`shadow_mode:auto` 不再运行 shadow，需要采样时手动 `force`。这一条必须与门语义同时改——`shadow_status` 原先是唯一能关停付费 shadow 的开关，若只删门槛而不改判定，shadow 会无限期每天多跑一遭完整管线。**`shadow_status` 因此必须保持零网络 I/O**：判定成了常量之后，读 Issue 只可能让这一步失败，而 `shadow-policy` 把非零退出当作「状态未知」并 fail-open 去跑付费 shadow，一次限流就会为一个毫无疑问的结论买单十分钟管线；同理 `main()` 在这条分支上不构造 `GitHubClient`（构造函数缺 token 即抛），job 也不再声明 `issues: read`。
- enrich 文字质量改为人工随时抽查，不再计入连续日。台账继续自动记录 `removed_fields / enrichment_audited_events` 安全指标。
- 45 条夹具三轮门与配对成本门随之退役，降为可手动触发的质量探针。`Objectivity Acceptance` workflow 保留，仍只读、仍只允许从 `main` 触发。

## 代价与被接受的风险

不再存在「客观性 active 已通过线上验收」这条路径；未来若要启用，必须重新设计验收方式，而不是接着数天数。客观性 shadow 的聚合指标从每日变为按需采样，来源集中度和独立证据链的观察密度因此下降。

配对成本门不再自动拦截夹具路径上的成本回归：2026-08-09 的 Run 31294396802（`c9e6874`）质量四门全过（红线 0、标签一致率 93.33%、归因 100%、结构 100%）但配对成本门失败，调用数 300 → 316、标准化费用 `$0.04210262` → `$0.04326518`，且截断、终止与计费错误均为 0。该结果保留为历史诊断证据，不再作为阻塞项——同期公开日报的实际调用数为 121 → 109 → 96，呈下降趋势，成本回归只出现在夹具路径上。日常成本改由 `cost_guard` 的非阻断告警兜底（正式生成超 `$0.06`、shadow 超 `$0.09`）。

「任何门失败都不通过减少审计、增加预算、切换供应商或追加调用补救」这条纪律继续有效，适用于仍然存在的日常告警与手动探针。
